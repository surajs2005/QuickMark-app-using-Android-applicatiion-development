# QuickMark - Attendance App

QuickMark is an Android app for easy attendance tracking. Mark, view, and manage attendance with a clean Material Design UI. Built with Kotlin/Java, MVVM, Room DB, and optional API integration for seamless attendance management.

## Features
- Mark and update attendance  
- View daily, weekly, and monthly records  
- Manage classes and students  
- Clean Material Design interface  
- Local storage with Room DB  
- Optional API integration  

## Tech Stack
- **Language:** Kotlin / Java  
- **Architecture:** MVVM  
- **Database:** Room  
- **Networking:** Retrofit (optional)  
- **UI:** Material Design, RecyclerView, ViewBinding
